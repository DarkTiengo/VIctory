# Collaboration

Another contributor is actively updating this repository. The owner requires
checking their updates throughout development.

- Before editing, inspect the current remote default branch, relevant working
  branches, open pull requests and task ownership in `CONTRIBUTING.md` and
  `docs/lab/tasks.md`. Compare changed files with the local work.
- Recheck remote updates at integration milestones during long tasks and before
  committing, pushing or opening a pull request. Avoid duplicating fixes already
  merged or being developed in an open pull request.
- Record the remote commit checked. If terminal Git networking is unavailable,
  use the connected GitHub tools for inspection and state whether the checkout
  has actually been synchronized; remote inspection alone is not synchronization.
- Preserve local uncommitted work and integrate relevant incoming changes before
  dependent implementation. Resolve overlaps using both versions; never overwrite
  another contributor's work or force-push shared branches.
